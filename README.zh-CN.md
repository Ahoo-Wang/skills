## 安装

### 在 Claude Code 中安装

```bash
/plugin marketplace add https://github.com/Ahoo-Wang/skills
/plugin install ahoo-wow-skills
```

### 在 Codex 中安装

```bash
codex plugin marketplace add Ahoo-Wang/skills --ref main
codex plugin add ahoo-wow-skills@ahoo-skills
```

按上表安装需要的拆分插件即可。

上游技能每 6 小时同步一次。每个插件的版本号由其自身内容计算得出，只有该插件的技能变化时
才会出现新版本。在 Claude Code 中运行 `/plugin update` 即可获取最新技能。

## 工作原理

上游仓库维护自己的 skills，并在 `skills/plugins.json` 中声明如何拆分为插件。本仓库只负责分发：

- `repos.json` 列出源仓库。
- `npm run sync` 对每个源仓库做 shallow clone，把其插件声明的 skills 复制到
  `plugins/<plugin>/skills/`，并把源 commit、插件元数据和每个 skill 的内容哈希记录在
  `skills.lock.json`。若上游只有 commit 变化而内容未变，lock 保持不变，不产生任何改动。
- `npm run build` 从 `skills.lock.json` 和 `plugins/` 派生其余一切：两份插件清单、
  内容派生的版本号、Claude Code 与 Codex 的 marketplace、上面的插件表，以及 `docs/` 中的
  [网站](https://skills.ahoo.me/zh-CN/)页面。
- `npm run check` 重新派生并比对，任何差异、手工修改过的生成 skill 或格式错误的 skill
  都会失败。CI 通过 `npm test` 运行它。
- `.github/workflows/sync-skills.yml` 每 6 小时同步一次并提交结果。

插件版本号为 `1.0.0+<插件文件哈希>`，仅当该插件内容变化时才会改变。

添加源仓库：确认其提供 `skills/plugins.json`，加入 `repos.json` 后运行 `npm run sync`。
添加本仓库维护的插件：创建包含两份清单和 skills 的 `plugins/<plugin>/`，然后运行 `npm run build`。

```
plugins/<plugin>/
├── .claude-plugin/plugin.json
├── .codex-plugin/plugin.json
└── skills/<skill>/SKILL.md
```
