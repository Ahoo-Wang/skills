A central aggregation repository for [Agent Skills](https://agentskills.io/) from [Ahoo-Wang](https://github.com/Ahoo-Wang)'s open source projects.

Skills are automatically synced from source repositories **every 6 hours** via GitHub Actions (or on demand with `gh workflow run sync-skills.yml --repo Ahoo-Wang/skills`) and published as split plugins by source project.

## Installation

### Install in Claude Code

```bash
/plugin marketplace add https://github.com/Ahoo-Wang/skills
/plugin install ahoo-wow-skills
```

### Install in Codex

```bash
codex plugin marketplace add Ahoo-Wang/skills --ref main
codex plugin add ahoo-wow-skills@ahoo-skills
```

Install the specific split plugin you need from the table above.

Upstream skills are synced every 6 hours. Each plugin's version is derived from
its own content, so a plugin gets a new version only when its skills change. Run
`/plugin update` in Claude Code to pull the latest skills.

## How It Works

Upstream repositories own their skills and declare how they are split into
plugins in `skills/plugins.json`. This repository only distributes them:

- `repos.json` lists the source repositories.
- `npm run sync` shallow-clones each source, copies the skills its plugins
  declare into `plugins/<plugin>/skills/`, and records the source commit, the
  plugin metadata and a hash of every mirrored skill in `skills.lock.json`.
  When only upstream commits moved, the lock is kept and nothing changes.
- `npm run build` derives everything else from `skills.lock.json` and
  `plugins/`: both plugin manifests, their content-derived versions, the Claude
  Code and Codex marketplaces, and the plugin table above.
- `npm run check` re-derives all of that and fails on any difference, on
  generated skills edited by hand, and on malformed skills. CI runs it with
  `npm test`.
- `.github/workflows/sync-skills.yml` runs the sync every 6 hours and commits
  the result.

A plugin's version is `1.0.0+<hash of its files>`, so it changes exactly when
that plugin's content changes.

To add a source repository, make sure it publishes `skills/plugins.json`, add it
to `repos.json`, and run `npm run sync`. To add a plugin maintained here, create
`plugins/<plugin>/` with both manifests and its skills, then run `npm run build`.

```
plugins/<plugin>/
├── .claude-plugin/plugin.json
├── .codex-plugin/plugin.json
└── skills/<skill>/SKILL.md
```
